## 1. 무엇을 만드나요?

**포스터 접근성 검수 도구**예요. 디자이너가 포스터 PSD를 올리면 저시력자·색각이상자·시야가 좁은 사람이 읽기 어려운 글자를 찾아요. 그리고 고친 모습을 원본 옆에 보여주고, 고친 PSD·이미지·큰 글씨 안내문을 내려받게 해요.

- 사용 화면: https://poster-a11y-chi.vercel.app (설치 없이 브라우저에서)
- 개발자 도구: https://poster-a11y-chi.vercel.app/dev.html
- 포토샵 플러그인(UXP): 뼈대만 있어요. 실제 포토샵에서는 아직 확인하지 않았어요

## 2. 왜 중요한가요? (누구의 어떤 불편)

| 누가 | 어떤 불편 |
| --- | --- |
| **저시력자** (시력 0.3 이하, 국내 시각장애 기준 0.2 이하) | 작은 글자나 대비가 낮은 글자는 가까이 가도 못 읽어요. 공연 날짜·장소·가격처럼 꼭 필요한 정보를 놓쳐요 |
| **색각이상자** (비율은 '색각이상 시장조사' 자료 기준으로 채우기, 팀 확인 필요) | 색만 바꿔 강조한 정보(예: 빨간 '매진')를 구분하지 못해요. 빨강·초록 글자처럼 밝기가 비슷하면 잘 안 보여요 |
| **시야가 좁은 사람** (녹내장 등, 시야 10° 이하) | 정보가 포스터 여기저기 흩어져 있으면 한 번에 보지 못하고 놓쳐요 |
| **디자이너** | 접근성 기준(WCAG)을 잘 몰라요. 어디를 얼마나 고쳐야 하는지 알기 어려워요. 고치면 디자인이 망가질까 걱정해요 |

## 3. 핵심 기능

> **화면 원칙 (11/20 멘토 피드백):** 처음 쓰는 사람에게 정보가 너무 많으면 안 돼요. 한 화면에 한 가지만, 가장 중요한 것부터 보여줘요. 정보 전달 지도는 **고치는 순서를 정하는 근거**로 쓰고, 사용자에게는 단순한 결과만 보여줘요.


0. **홈 화면**: 뭐 하는 곳인지, 누구를 위한 건지, 샘플로 보는 '저시력자에게는 이렇게 보여요 → 고치면 이렇게 보여요' 비교
1. **용도와 보는 사람 고르기**: 예술 / 정보 전달 / 잘 모르겠음, 시력 단계(일반·저시력 0.3·시각장애 0.2·심한 장애 0.06), 시야(보통·10°·5°)
2. **검사**: 글자 크기(보는 거리의 각도), 대비, 굵기, 자간·행간, 글꼴 가독성, 색 의존 정보, 색각이상 대비, 겹침·잘림, 위계·묶음, 시야 안 정보 모음
3. **고친 모습 미리보기**: 원본과 고친 모습을 나란히 보여줘요. 항목의 '고친 뒤' 그림을 누르면 그 수정이 적용돼요
4. **정보 전달 지도**: 어디부터 고쳐야 하는지 순위로 보여줘요. 지도와 목록에서 바로 고칠 수 있어요
5. **다른 눈으로 보기**: 저시력(흐림), 황반변성, 녹내장, 백내장, 당뇨망막병증, 색각이상 3종, 어두운 조명 시뮬레이션
6. **내려받기**: 접근성 버전 PSD·PNG·JPG, A4 큰 글씨 안내문(PDF·PNG)
7. **원본 보호**: 원본 PSD는 절대 바꾸지 않아요. PSD는 서버로 올라가지 않고 브라우저 안에서만 처리해요

### 사용자 동선

홈 → **준비**(용도·보는 사람·PSD 올리기) → **하나씩 고치기**(중요한 순서로 하나씩, 다음 버튼) → **마무리**(다른 눈으로 비교, 최종 변환하고 받기)

| 순서 | 할 일 | 상태 |
| --- | --- | --- |
| 1 | 홈 화면 (설명, 대상, 샘플 전후 비교) | 완료 (#18) |
| 2 | 단계 표시줄 + 준비 화면 (꼭 필요한 설정 2개만) | 완료 (단계 표시줄 #20, 준비 화면 #21) |
| 3 | 하나씩 고치기 화면 (고치기·건너뛰기·다음, 눈에 띄는 번호 버튼) | 완료 (번호 버튼 #19, 하나씩 고치기 #22) |
| 4 | 마무리 화면 (요약, 다른 눈으로 보기, 최종 변환하고 받기) | 완료 (이 PR) |

## 4. 이번에 하지 않는 것

- **로그인, 회원가입, 결제**
- **서버·DB 저장**: 검사 결과를 저장하거나 공유하지 않아요. 모든 처리는 브라우저 안에서 해요
- **자동 재배치**: 글자 위치를 옮기거나 줄바꿈을 바꾸지 않아요. 디자이너가 판단할 일이에요
- **그림(이미지) 속 글자 읽기(OCR)**: 텍스트 레이어만 검사해요
- **PSD 말고 다른 파일 형식** (AI, PDF, Figma 등)
- **합격·불합격 공식 인증**: 기준값은 아직 임시값이에요. 법적 인증 도구가 아니에요
- **포토샵 플러그인 완성**: 이번에는 웹이 먼저예요. 플러그인은 가능성 확인까지만 해요 **(팀 확인 필요)**

**화면만**이에요. Vercel에 정적 페이지로 배포하고, 서버와 DB는 쓰지 않아요. 저장·로그인이 필요해지면 그때 Supabase 같은 DB를 검토해요.

## 7. 발표할 때

웹으로 만든 이유와 앞으로의 계획을 이렇게 말해요.

> 지금은 웹으로 만들어서 설치 없이 바로 써 보고 발표하기 좋아요. 앞으로는 디자이너가 작업하는 곳에서 바로 쓸 수 있게 **포토샵 플러그인**으로 만들 생각이에요. 그래서 PSD 읽기·데이터 형식·검사 엔진은 웹과 플러그인이 같이 쓰도록 이미 나눠 두었어요.
